# NisEduScopeFront — краткое описание

## Назначение

Фронтенд админ-панели школы для **мониторинга изменений школьных оценок**: отображение данных и дашборд для администраторов.

## Архитектура

- **Этот репозиторий:** SPA на Vite + React (отдельно от бэкенда).
- **Бэкенд:** вынесен в отдельный проект; фронт взаимодействует с API по HTTP (например, axios).

## Стек (из `package.json`)

- React 19, Vite 8, TypeScript-окружение через типы React
- TanStack Query, axios, recharts, lucide-react
