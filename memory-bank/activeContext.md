# Текущий фокус

**Режим:** VAN (после инициализации)

**Проект:** `NisEduScopeFront` — админский фронт с дашбордом для мониторинга изменений школьных оценок.

**Интеграция:** бэкенд отдельно; при разработке UI и запросов опираться на контракт API из бэкенд-репозитория или `.env` с базовым URL.

**Ожидание:** следующее сообщение пользователя с конкретной задачей (экран, график, фильтр, ошибка сборки и т.д.).
